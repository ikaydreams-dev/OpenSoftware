# EnglishCode IDE

> **Desktop IDE for EnglishCode** - Programming in Plain English

A beautiful, modern IDE built with Tauri 2.0, React, and Monaco Editor.

## Features

- Monaco Editor with syntax highlighting
- One-click code execution
- Real-time output display
- Native macOS app (3.0MB)
- Dark theme interface

## Installation

Download `engcode-ide_0.1.0_x64.dmg` and drag to Applications.

## Usage

1. Write EnglishCode in the editor
2. Click ▶ Run button
3. See output below
