# EnglishCode Examples

This directory contains real-world examples demonstrating EnglishCode's capabilities.

## Running Examples

```bash
engcode run examples/filename.eng
```

## Available Examples

1. **ecommerce-setup.eng** - Complete e-commerce database structure
2. **saas-platform.eng** - Multi-tenant SaaS application setup
3. **social-network.eng** - Social media platform database
4. **project-management.eng** - Project management system
5. **healthcare-system.eng** - Healthcare patient management

Each example demonstrates production-ready database architecture and collections.
